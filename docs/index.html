GazeCam

Віртуальна камера для macOS, яка виправляє погляд. Ви дивитесь на співрозмовника на екрані, а на відео виглядає, ніби дивитесь просто в камеру.

Початок роботиТренуванняGitHub

Як це працює

Камера→Vision: точки очей→кроп кожного ока→Core ML: потік + світло→вставка назад→віртуальна камера

Застосунок у рядку меню бере кадр із реальної камери, знаходить очі, «доводить» зіниці до камери нейромережею-деформатором і віддає результат через розширення CoreMediaIO. У Zoom, Meet, FaceTime тощо просто оберіть камеру GazeCam.

Початок роботи

Що потрібно

  • Mac на Apple Silicon (arm64), macOS 14+
  • Xcode і XcodeGen (brew install xcodegen)
  • Обліковий запис Apple Developer: системні розширення треба підписувати

Збірка і встановлення

git clone https://github.com/tggo/gazecam.git
cd gazecam
make dev        # xcodegen → xcodebuild (Release) → /Applications → запуск
Системні розширення активуються лише з /Applications, тому make dev встановлює застосунок саме туди.

Makefile підписує збірку через ключ App Store Connect API (~/.appstoreconnect/private_keys/AuthKey_<ID>.p8). Підставте свої значення:

make dev ASC_KEY_ID=XXXXXXXXXX ASC_ISSUER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Або відкрийте GazeCam.xcodeproj після make generate і виставте свою команду в Signing.

Перший запуск

  1. В іконці в рядку меню натисніть «Встановити камеру» і дозвольте розширення в Системних параметрах → Загальні → Входи та розширення.
  2. Оберіть реальну камеру в пікері «Камера».
  3. Відкрийте «Превʼю і налаштування…»: увімкніть «Поруч з оригіналом», щоб бачити ефект, а «Оверлей» покаже знайдені очі.
  4. У застосунку для дзвінків оберіть камеру GazeCam.

Логи: make logs. Видалити розширення можна кнопкою «Видалити» в меню.

Тренування під себе

Стокові ваги працюють на будь-кому, але найкраще мережа поводиться, коли її донавчити на вашому обличчі, камері й відстані. Персональних моделей у репозиторії немає: ви тренуєте їх самі.

МодельЩо робитьСкрипти
GazeWarpUser{L,R}донавчений деформатор очейfinetune.py, export_coreml.py
GazeEstimatorоцінює, куди ви дивитесь (замість евристики зіниць)train_estimator.py, export_estimator.py

1. Середовище

cd train
python3.12 -m venv .venv && source .venv/bin/activate
pip install torch==2.7.0 tensorflow==2.20.0 coremltools==9.0 numpy opencv-python

TensorFlow потрібен лише для одноразового завантаження оригінальних TF1-чекпойнтів. На Mac тренування йде на MPS, приблизно 1 с на епоху.

2. Оригінальні ваги «Look at Me!»

Завантажте чекпойнти з chihfanhsu/gaze_correction і вкажіть шлях у DEFAULT_WEIGHTS / DEFAULT_REPO в load_tf.py. Перевірка паритету TF ↔ torch:

python load_tf.py          # пише parity.json

3. Збір датасету

У вікні превʼю натисніть «Збір датасету (≈45 с, 18 точок)». По екрану бігає точка (сітка 3×3), і кожні кілька точок треба подивитись у камеру. Дивіться на точку, голову тримайте як під час звичайного дзвінка. Кадри з мітками зберігаються в:

~/Movies/GazeCam/dataset/<сесія>/NNNN.jpg + labels.csv
Зберіть щонайменше 5–6 сесій на різних відстанях і з різним світлом. Одну відкладіть для валідації, а для оцінювача ще одну для тесту. З однієї-двох сесій мережа перенавчиться.

Перевірте, скільки пар залишилось після фільтрів (кліпання, саккади, дублікати):

python dataset.py --sessions ~/Movies/GazeCam/dataset/* --stats
python dataset.py --sessions ~/Movies/GazeCam/dataset/* --sign-check   # знак кута; очікувано (+,-)

4. Донавчання деформатора

VAL=2026-10-16_19-09-30     # назва вашої відкладеної сесії
python finetune.py --side R --val-session $VAL --lr 3e-5 --epochs 12 --patience 4 --out runs/R
python finetune.py --side L --val-session $VAL --lr 3e-5 --epochs 12 --patience 4 --out runs/L
python export_coreml.py --side R --ckpt runs/R/best.pt --out export_finetuned
python export_coreml.py --side L --ckpt runs/L/best.pt --out export_finetuned

Валідація зазвичай найкраща вже на 1–2 епосі, далі мережа перенавчається, тож багато епох не потрібно. Піксельний L1 не показує, чи справді «дивиться в камеру», тому перевіряйте результат очима в превʼю.

Встановлення: експорт пише GazeWarp{L,R}.mlpackage, а застосунок шукає GazeWarpUser{L,R}:

cp -R export_finetuned/GazeWarpR.mlpackage ../GazeCam/Models/GazeWarpUserR.mlpackage
cp -R export_finetuned/GazeWarpL.mlpackage ../GazeCam/Models/GazeWarpUserL.mlpackage

5. Оцінювач погляду (необовʼязково)

Спершу пропишіть свої сесії в SESSIONS у estimator_data.py (train / val / test), потім:

python train_estimator.py --epochs 60 --patience 100 --out runs/est
python export_estimator.py --ckpt runs/est/best.pt --out export_estimator
cp -R export_estimator/GazeEstimator.mlpackage ../GazeCam/Models/

Мережа має 291k параметрів, інференс займає близько 0,12 мс. На тестовій сесії автора похибка вийшла 4,6° по вертикалі і 2,9° по горизонталі, тоді як евристика зіниць дає 12,3° і 6,4°. Результати помітно гуляють між запусками, бо даних мало.

6. Увімкнути у застосунку

cd .. && make dev

У превʼю оберіть свою модель у пікерах «Модель корекції» і «Куди дивлюсь — оцінка». Якщо файлів немає, застосунок просто працює на стокових вагах і зіницях Vision.

Деталі вимірювань (паритет, знаки кутів, таблиці метрик) описані в train/README.md.

Мережа-деформатор і її передтреновані ваги взяті з роботи «Look at Me! Correcting Eye Gaze in Live Video Communication» (Chih-Fan Hsu, Yu-Shuen Wang, Chin-Laung Lei, Kuan-Ta Chen, ACM TOMM 2019, github.com/chihfanhsu/gaze_correction). Усі права на оригінальну модель належать її авторам.
